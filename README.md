# Devie QT

A local desktop tracker for AI subscription quotas.

The project is in the requirements and feasibility stage. Read the
[feasibility analysis](plans/feasibility-analysis.md) before the POC starts.

Initial provider scope:

- Claude
- OpenAI Codex
- GitHub Copilot

The working application stack is Tauri 2, Rust, Next.js, React, and Devie UI.
